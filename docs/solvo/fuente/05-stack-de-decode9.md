# Stack de decode9

Herramientas probadas que Jorge Bastidas (decode9) elige por confiabilidad y
escala, no por moda.

- Lenguajes: TypeScript, JavaScript, Python, Kotlin, Java, C#, PHP.
- Frontend, mobile y motion: React, Next.js, React Native, Expo, Angular, Tailwind, three.js, GSAP.
- Backend y APIs: Node.js, Express, NestJS, FastAPI, REST, gRPC, microservicios.
- Datos: PostgreSQL, pgvector, MySQL, MongoDB, SQLite con SQLCipher, MSSQL.
- Nube: AWS (Lambda, API Gateway, CloudFront, RDS, Amplify), Azure, Google Cloud, DigitalOcean.
- DevOps e infraestructura como código: Terraform, Docker, Kubernetes, GitHub Actions, GitLab CI, Jenkins, SonarQube.
- IA y automatización: tool calling con LLMs, RAG, MCP, agentes de IA, guardarraíles, n8n.

Para un MVP SaaS nuevo, el punto de partida habitual de decode9 es Next.js con
TypeScript, una API en Node.js, PostgreSQL e infraestructura serverless en AWS
con Terraform; la elección final depende del problema.
