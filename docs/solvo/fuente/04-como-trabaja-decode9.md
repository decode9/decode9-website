# Cómo trabaja decode9

Jorge Bastidas (decode9) sigue un camino claro desde el problema hasta un
producto funcionando que se puede defender: ingeniería con mentalidad de
producto, no sólo código.

1. Descubrir: entender el objetivo, las restricciones y qué significa el éxito.
2. Arquitectar: diseñar un sistema que encaje con el problema y crezca.
3. Construir: código limpio, probado y de nivel producción, en iteraciones cortas.
4. Automatizar: quitar trabajo manual con pipelines e integraciones confiables.
5. Lanzar: desplegar con CI/CD, monitoreo y confianza.
6. Iterar: medir, refinar y mantener el sistema funcionando mientras escala.

## Cómo empezar un proyecto con decode9
Escribir a jbastidas@theempire.tech contando qué se quiere construir. Jorge lee
y responde cada mensaje, y propone la forma más rápida y confiable de lanzarlo.
También se pueden dejar nombre y correo en la conversación con el guía del
sitio. Trabaja en remoto con clientes de todo el mundo.
